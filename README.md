# Faculty React Project

## 📌 Project Description

This project is a Faculty website built using **React.js**.
The website provides information about the faculty, its departments, programs, faculty members, services, events, news, and contact information.

The project also supports **English and Arabic languages**, including RTL (Right-to-Left) support for Arabic.

## 🚀 How to Run the Project

### 1. Clone the repository

```bash
git clone https://github.com/MalakMagdy2007/Faculty-React-Project.git
```

### 2. Open the project folder

```bash
cd Faculty-React-Project
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

### 5. Open the website

Open the local URL shown in the terminal, usually:

```text
http://localhost:5173
```

---

## 🌐 Language Support

The website supports two languages:

* English
* Arabic

When Arabic is selected:

* The website content changes to Arabic.
* The page direction changes to RTL.
* The selected language is saved in Local Storage.

---

## 🧩 Main Libraries

### React

Used to build the user interface using reusable components.

### React Router DOM

Used for navigation between the different pages without reloading the website.

### i18next & react-i18next

Used to implement English and Arabic translations.

### Vite

Used as the development and build tool for the React project.

### Lucide React

Used for icons throughout the website.
